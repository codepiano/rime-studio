# 使用指南

## 第一次使用：确认实际配置目录

工作台依次检查系统安装、当前用户的安装及 Rime 用户目录。检测结果是候选，不自动等同于正在使用的配置。

请在菜单栏切换到鼠须管，从它的菜单打开用户文件夹，核对“连接设置”里的用户目录；内置目录需包含 `default.yaml` 和 `squirrel.yaml`。确认后点击“确认实际目录并连接”。

如果没有检测到目录，页面会提示手动填写；可以使用绝对路径或 `~/`。设置记在工作台自己的 `.data/settings.json`，不会写入 Rime 文件。可以随时从“连接设置”切换或恢复自动检测。

不同目录的清单、备份和预览相互区分。副本只会被编辑，不会改变鼠须管正在使用的位置；不是原生目录时不请求系统重载。启动环境变量指定的目录优先于页面设置。

## 先理解这三个状态

- **待应用**：网页里的修改，还没有写到 Rime 文件。
- **已保存**：预览中的配置、方案或词库文件已经修改并备份，需要重新部署。
- **编译产物已更新**：观察到 Rime 更新了配置，仍应在实际输入框检查行为。

网页展示的是读取到的配置或已部署映射，并不直接报告当前输入会话选中的方案和每个开关的实时状态。

## 调整候选窗口

打开“调整我的输入 → 候选与外观”。右侧是整页共享的预览，数量、排列、字体、字号和配色都在同一处呈现；滚动到配色区域时，预览仍保持可见。小屏幕上，预览放在所有设置之前。

“在输入位置显示编码”控制尚未选字时预编辑文本的显示位置：开启后显示在正在打字的输入框里，关闭后显示在候选窗口。显示原始双拼码还是展开的拼音，由方案的 `preedit_format` 等规则决定，和位置开关分开。

示例候选不来自运行中的 Rime。真实字体、原生配色和窗口定位以鼠须管为准。

## 修改并应用

1. 调整控件，把需要的修改加入清单。
2. 打开“待应用”，取消不想保留的项。
3. 点击“生成修改预览”，检查每个文件的差异；绿色是新增，红色是删除，深色部分是行内变化。
4. 确认后保存。新文件会标注“新建文件”。
5. 请求重新部署；未能确认时使用系统输入法菜单里的“重新部署”。
6. 回到真实输入框确认实际效果。

配置被其他程序修改后，已有预览会失效，需要重新读取和预览。

## 找一个忘了怎么输入的符号

打开“随用随查 → 找符号”，或使用顶部搜索。

- 输入日常描述，例如“外国人名”“圆点”“省略号”。
- 已有字符时，直接粘贴它反查。
- 选择需要查询的输入方案。
- 查看推荐按法、候选位置及半角 / 全角范围。
- 可以展开其他输入方式，或直接复制字符。

查询依据所选方案已部署的映射，需在合适的中文标点模式中使用。方案还未部署时不会凭空显示默认快捷键。Shift 组合按常见键盘布局显示，实际键位可能因布局而异。

例如小鹤双拼常见默认映射中，`|` 的首个候选是人名间隔号 `·`；网页会按照实际配置显示是否仍如此。

## 移除误选词的记忆

打开“把误选的词从记忆中移除”操作卡。

练习里可以点击候选，也可以用 ↑ ↓ 选择；高亮、勾选标记和“当前选中”文字一起显示选择状态。选中示例用户词“拟好”之后才启用移除按钮；操作后它从示例列表消失，并可以重新练习。

真实操作是在重新输入相同编码后的候选栏里，用方向键高亮目标用户词，再按相应的删除用户词快捷键。Mac 常见按法为 `Shift + Fn + Delete`。原始词库中的词不能删除，只取消调频。这个操作不会删掉已经写进文档的文字。

网页练习只改变示例状态，不修改真实词库。

## 给应用设置默认语言

打开“应用习惯”。选择应用默认中文或英文；添加新应用时填写应用标识，例如 `com.apple.TextEdit`。

只调整默认语言。已有的行内编辑、Vim 模式等兼容规则保留。恢复继承是移除自定义语言覆盖，回到内置规则，不是强制中文。

## 修改方案的默认状态

“语言与词库”先选择方案，再修改语言、字形、标点或用户词库开关。默认状态对应新会话，已有状态记忆可能优先。

在“输入方案”可以勾选已安装方案并调整菜单顺序。安装、启用和当前会话正在使用是三件事；当前运行方案通过 Rime 自己的菜单查看。

## 恢复继承与撤销

- **恢复继承**：删除一个设置的自定义覆盖。遇到无法安全拆分的整段覆盖或高级列表补丁，会拒绝自动修改。
- **恢复修改前配置**：在“修改记录”恢复一批保存前的文件。文件有后续变化时拒绝覆盖；第一次创建的文件可恢复为不存在。

恢复后仍需重新部署。备份包含本次保存的配置、方案文件、静态词库、短语和模型；学习记录删除还会备份对应数据库，之后有新学习变化时拒绝覆盖恢复。请自行保管 `.data/backups/`，不要上传公开仓库。

## 看懂输入方案

“看懂输入方案”优先使用已有编译产物展示真实组件顺序，点击组件了解职责，并可查阅官方方案设计文档。分组用于解释处理阶段，不表示组件之间只有单向数据流。

## 获取和更新方案

打开“方案与词库 → 获取和更新方案”，选择雾凇或白霜，点击下载。下载需要 Git 和网络，完成后显示文件预览，尚未写入 Rime 用户目录。

首次完整安装会把主方案加入菜单首位，保存后可在“输入方案”调整启停与顺序。上游的个人短语样例和 `.custom.yaml` 不会导入，但其他同名源文件可能被替换，务必核对预览。保存后请求重新部署。

安装记录绑定实际下载的提交和每个文件的 SHA-256。“检查整套更新”包含方案、词库、Lua、OpenCC 与随包模型；“只更新词库”只更新 `.dict.yaml`，需要已由知键完整安装该方案。更新不会强制重新启用或调整菜单顺序。

已被本地修改的上游文件会保留并列为冲突；需要核对与新文件的兼容性。上游删除的文件暂时保留，不自动移除。下载任务只在当前服务进程中保留，预览有效期为十分钟。重启或预览过期后重新下载和预览。

## 查询词库与添加个人词条

“我的词库”显示已发现的文本词库、来源目录、引用关系及所选方案的主词库。存在编译配置时优先显示编译后的引用；保存后需部署才能刷新这些关系。

点击词库，按文字或编码搜索，每页最多显示 100 条。原词库只读；点击“编辑个人扩展词库”，添加文字、完整编码及权重，预览后保存。个人词条另存为独立词库，扩展入口展开原词库依赖，同时保留原来的用户学习词典名称。

双拼方案的词库通常仍使用全拼编码，不能直接填写按键缩写。带声调或辅助码的编码需遵循原词库。特殊列结构、缺失依赖和引用循环拒绝自动扩展。

## 编辑快捷短语

“快捷短语”选择方案后自动读取已识别的 `tabledb` 或 `stabledb` 文本表，雾凇的 `custom_phrase` 也可使用。引用多个固定文本表时可逐表选择，不合并它们。若多个方案共用同一文件，会显示受影响的方案。

不存在可识别的短语翻译器时，首次保存会创建独立短语文件，并预览接入方案的配置补丁；不安全的高级补丁会拒绝合并。接入依据已保存的源配置，避免尚未重新部署时重复接入旧配置。

填写文字、输入短码和可选权重。可筛选文本／编码、按权重查看、导入或导出 UTF-8 的 Tab 分隔文本。相同编码的不同文字允许成为多个候选，并提示重码；重复的文字与编码、无效权重或多余列会拒绝保存。原有注释、空行、BOM、换行方式和未修改条目保持原样。最多 2000 条、100 KB，每条最多 500 个字符；不支持多行输出。

页面切换会在当前页面会话中保留草稿，刷新整个浏览器或关闭页面不等于保存。若外部文件或方案配置变化，显示最新内容并提供旧草稿导出，不直接覆盖。先预览，再保存和重新部署；从“修改记录”恢复时检查外部变更。

固定短语用你指定的短码输出，个人扩展词库用词库编码并可参与造词，学习词典则记录输入时的学习与调频；三者分别管理。短语短码必须使用当前方案能接收的按键，知键不会自动改变方案的按键字母表。

## 查询系统词典

打开“查词与文字工具 → 系统词典”，输入字词后按回车或点击“查询释义”。查询使用 macOS Dictionary Services，返回本机已启用词典中首个匹配记录的纯文本释义，不提供指定词典或完整多词典结果。

查不到时，先在 macOS“词典”应用的设置中启用对应词典，再换词重试。首次查询需要 macOS 命令行工具（clang）构建一个小型本机程序；缺少工具或查询失败会明确提示，其他功能仍可使用。辅助程序保存在工作台 `.data/native/`，不复制系统词典数据。

可以复制释义，或把查询的字词加入快捷短语；后者会转入编辑表，需补上短码、预览并保存，不直接改动个人词库或学习记录。词典查询独立于 Rime 连接，加入短语需要已确认的配置目录。

## OpenCC 工具箱

在“查词与文字工具 → OpenCC 工具箱”粘贴原文，选择简繁、台湾正体、香港繁体或台湾／大陆常用词转换，点击“转换文字”。支持 8 种转换方式，每次最多 30,000 个 UTF-16 字符单位，保留多行、空格和非中文文本。

原文与结果并排显示，窄屏上下显示。修改原文或转换方式会使旧结果失效，需要重新转换；可以复制结果，或“用结果继续转换”。结果为单行、最多 500 个字符时，可转入快捷短语编辑表。转换不会直接写 Rime 配置。

使用固定版本 `opencc-js 1.4.2`，转换字典随本地 npm 依赖提供，运行时不访问 CDN 或云端接口。它是 OpenCC 的 JavaScript 实现，和原生 OpenCC 并非对所有文本保证完全一致；繁简转换也不能代替人工校对。

## 通过 plum 获取更多方案

“方案与词库 → 获取和更新方案”下方增加 plum 入口。填写配方名称，或点击默认方案集、双拼、五笔、粤拼、表情符号等快捷项，然后点击“通过 plum 准备并预览”。可输入多个配方，以空格分隔。

示例：`:preset`、`double-pinyin`、`wubi pinyin-simp`、`iDvel/rime-ice@main`、`gaboolic/rime-frost@master:others/recipes/full`。也支持简单配方参数，例如 `emoji emoji:customize:schema=luna_pinyin`，将 Emoji 资源接到朙月拼音。

这里填写的是配方名称，不是 README 里的整条终端命令。知键固定调用官方 `rime-install`，把目标目录明确指定为暂存目录；准备完成后才展示修改。保存仍通过知键的备份和外部修改检查，之后单独部署。启用与排序在“输入方案”里调整；配方自身若改变方案菜单，也会出现在预览中。

雾凇、白霜的上方按钮继续使用专门适配。通过 plum 安装白霜时使用官方 `others/recipes/full` 配方。只输入白霜仓库名或 `@master` 也会解析到这个入口；显式指定其他配方时保留用户选择。不再笼统复制整个仓库目录作为补齐。完整配方不一定包含全部模型或增强功能资源，缺少依赖会拒绝保存。已有个人 `custom_phrase.txt` 保留；其他配方可能修改 `.custom.yaml`，请核对预览。

目前支持官方 `:preset`／`:extra`／`:all`、GitHub 仓库、分支和简单 ASCII 键值参数。不接受任意终端命令、直接 URL、外部 packages.conf 或安装器自更新；也不会自动应用文件删除。特殊配方依赖的额外工具、插件及高级配置读写可能不受支持，失败时不会自动回退为直接修改真实目录。


## 管理输入过程中学会的词

“方案与词库 → 学会的词”管理学习词典，和手动“个人扩展词库”分开。点击“读取最新学习记录”，读取所有发现的学习词典，按词条或完整编码搜索、筛选词典、翻页或导出查询结果。默认勾选“隐藏单字”，列表、匹配数量和导出均按此过滤；取消勾选可查看全部。该选项不会删除单字，也不改变“清空当前学习词典”的范围。可以显示已删除记录，但不能再次删除它们。

鼠须管持有数据库时，会显示“同步快照”及时间，或提示暂时无法读取。旧快照不代表实际学习总量。连接实际原生目录时，点击“同步当前学习记录”可在鼠须管运行中更新快照；它使用 Rime 原生用户资料同步，会按 Rime 的规则处理本机同步目录。界面只在观察到文件更新后显示“刚更新的快照”，未观察到更新时明确提示无法确认。快照只用于查阅，不能用于删除。删除前请先从输入法菜单切换到系统输入法，再使用“请求退出鼠须管”；退出完成后读取最新记录。配置副本不提供同步／退出／启动控制。

勾选要删除的词，点击删除，核对词条、完整编码、词典和数量，再点击“删除并备份”。“清空当前学习词典”需要先选择一个词典，也经过相同预览。它只删除有效学习记录，不移走数据库、不删除固定词库，也不阻止以后再次学会。删除通常不需要重新部署，处理完可重新启动鼠须管并从菜单选择。

“调整我的输入 → 修改记录”可恢复删除前的数据库，包括学习参数，而不只是词条次数。后续又有学习变化时拒绝覆盖。操作中断或回滚未能确认时，记录标为需要核对；退出鼠须管后可以尝试恢复，仍有后续变化时继续拒绝覆盖，请保留原始备份。

首次学习词典操作需要 macOS 命令行工具（clang）构建小型锁辅助程序；没有该工具时仍可读取已有快照，但不能安全编辑。仅查看同步快照不需要构建。词典导出为 TSV，包含词条、完整编码、使用次数、学习词典四列。

## 独立词库的安装、停用和卸载

“我的词库”选择方案，导入 UTF-8 的 `.dict.yaml` 文件（最大 20 MB）。可勾选安装后在当前方案启用；未勾选时仅安装文件。保存前显示文件与引用差异。输入方案的编码和词库编码需要兼容。

选择一个词库，在详情中可“在当前方案启用／停用”。操作会创建或更新独立扩展入口，不改写上游主词库，也保留原学习词典名称。多个方案共用一个词库时，每个方案分别控制；修改后需重新部署。原主词库不能直接停用，内置目录文件不能删除。

解除所有已发现的引用后，可以“卸载用户词库”。引用检查包括方案中的字典、反查和直接导入表，以及已有编译配置；高级 Lua 动态引用不保证完全识别。未能确认依赖时不删除。删除只作用于用户目录的源文件，若同名内置文件仍在，会明确提示只删除用户副本。删除与停用都可从修改记录恢复。

方案包更新可能再次提供被卸载的文件，独立停用配置仍保留。个人扩展词库现在也允许删除最后一条词，不会清空基础词汇或学习数据库。

## 统一搜索

按 `⌘ K` 聚焦顶部搜索框，可以搜索功能、操作卡、符号、个人词条和快捷短语。词条结果标明来源，点击“查看来源”跳转到对应方案／表；“诊断输入”会带入该词的保存编码和期望文本。

学习词条仅搜索你已经在“学会的词”中读取或同步过的记录。来源会区分最近读取与只读快照，并显示时间；搜索不会自动访问或同步学习数据库。源码词库中未收录到个人扩展的全部基础词汇不纳入顶部词条搜索，仍可在“我的词库”中选文件查询。

## 找出词条为什么打不出来

进入“输入诊断”，选择方案、填写实际按键，并可填写期望词条，点击“运行输入诊断”。页面会核对启用和部署状态、字母表、词库文件和短语挂载，然后用本机 Rime 引擎在临时目录里编译、返回真实候选。空格表示选词，例如 `cs ` 会尝试提交当前首选。

试输使用当前保存的源配置，默认中文、半角，不载入日常学习数据库。个人词库或快捷短语能否进入候选可以在这里验证；已有词频、应用语言规则、键盘布局以及真实输入法是否已重载，仍需在日常输入框中确认。大型词库的首次诊断可能较慢；缺少资源或工具时会明确显示原因。

保存短语后，部署提示可能显示“固定短语表及隔离会话已核对”，因为这种修改可能无需重新生成 YAML。它表示重载已请求且已核对保存内容，随后请在真实输入框试打。未观察到新编译产物时不会宣称部署已经完成。
