# 使用指南

## 第一次使用：确认实际配置目录

工作台依次检查系统安装、当前用户的安装及 Rime 用户目录。检测结果是候选，不自动等同于正在使用的配置。

请在菜单栏切换到鼠须管，从它的菜单打开用户文件夹，核对“连接设置”里的用户目录；内置目录需包含 `default.yaml` 和 `squirrel.yaml`。确认后点击“确认实际目录并连接”。

如果没有检测到目录，页面会提示手动填写；可以使用绝对路径或 `~/`。设置记在工作台自己的 `.data/settings.json`，不会写入 Rime 文件。可以随时从“连接设置”切换或恢复自动检测。

不同目录的清单、备份和预览相互区分。副本只会被编辑，不会改变鼠须管正在使用的位置；不是原生目录时不请求系统重载。启动环境变量指定的目录优先于页面设置。

## 先理解这三个状态

- **待应用**：网页里的修改，还没有写到 Rime 文件。
- **已保存**：预览中的配置、方案或词库文件已经修改并备份，需要重新部署。
- **编译产物已更新**：观察到 Rime 更新了配置，仍应在实际输入框检查行为。

网页展示的是读取到的配置或已部署映射，并不直接报告当前输入会话选中的方案和每个开关的实时状态。

## 调整候选窗口

打开“调整我的输入 → 候选与外观”。右侧是整页共享的预览，数量、排列、字体、字号和配色都在同一处呈现；滚动到配色区域时，预览仍保持可见。小屏幕上，预览放在所有设置之前。

“在输入位置显示编码”控制尚未选字时预编辑文本的显示位置：开启后显示在正在打字的输入框里，关闭后显示在候选窗口。显示原始双拼码还是展开的拼音，由方案的 `preedit_format` 等规则决定，和位置开关分开。

示例候选不来自运行中的 Rime。真实字体、原生配色和窗口定位以鼠须管为准。

## 修改并应用

1. 调整控件，把需要的修改加入清单。
2. 打开“待应用”，取消不想保留的项。
3. 点击“生成修改预览”，检查每个文件的差异；绿色是新增，红色是删除，深色部分是行内变化。
4. 确认后保存。新文件会标注“新建文件”。
5. 请求重新部署；未能确认时使用系统输入法菜单里的“重新部署”。
6. 回到真实输入框确认实际效果。

配置被其他程序修改后，已有预览会失效，需要重新读取和预览。

## 找一个忘了怎么输入的符号

打开“随用随查 → 找符号”，或使用顶部搜索。

- 输入日常描述，例如“外国人名”“圆点”“省略号”。
- 已有字符时，直接粘贴它反查。
- 选择需要查询的输入方案。
- 查看推荐按法、候选位置及半角 / 全角范围。
- 可以展开其他输入方式，或直接复制字符。

查询依据所选方案已部署的映射，需在合适的中文标点模式中使用。方案还未部署时不会凭空显示默认快捷键。Shift 组合按常见键盘布局显示，实际键位可能因布局而异。

例如小鹤双拼常见默认映射中，`|` 的首个候选是人名间隔号 `·`；网页会按照实际配置显示是否仍如此。

## 移除误选词的记忆

打开“把误选的词从记忆中移除”操作卡。

练习里可以点击候选，也可以用 ↑ ↓ 选择；高亮、勾选标记和“当前选中”文字一起显示选择状态。选中示例用户词“拟好”之后才启用移除按钮；操作后它从示例列表消失，并可以重新练习。

真实操作是在重新输入相同编码后的候选栏里，用方向键高亮目标用户词，再按相应的删除用户词快捷键。Mac 常见按法为 `Shift + Fn + Delete`。原始词库中的词不能删除，只取消调频。这个操作不会删掉已经写进文档的文字。

网页练习只改变示例状态，不修改真实词库。

## 给应用设置默认语言

打开“应用习惯”。选择应用默认中文或英文；添加新应用时填写应用标识，例如 `com.apple.TextEdit`。

只调整默认语言。已有的行内编辑、Vim 模式等兼容规则保留。恢复继承是移除自定义语言覆盖，回到内置规则，不是强制中文。

## 修改方案的默认状态

“语言与词库”先选择方案，再修改语言、字形、标点或用户词库开关。默认状态对应新会话，已有状态记忆可能优先。

在“输入方案”可以勾选已安装方案并调整菜单顺序。安装、启用和当前会话正在使用是三件事；当前运行方案通过 Rime 自己的菜单查看。

## 恢复继承与撤销

- **恢复继承**：删除一个设置的自定义覆盖。遇到无法安全拆分的整段覆盖或高级列表补丁，会拒绝自动修改。
- **恢复修改前配置**：在“修改记录”恢复一批保存前的文件。文件有后续变化时拒绝覆盖；第一次创建的文件可恢复为不存在。

恢复后仍需重新部署。备份包含本次保存的配置、方案文件、静态词库、短语和模型，不包含用户学习数据库。请自行保管 `.data/backups/`，不要上传公开仓库。

## 看懂方案与源码

“看懂输入方案”优先使用已有编译产物展示真实组件顺序，点击组件了解职责，再跳转源码。分组用于解释处理阶段，不表示组件之间只有单向数据流。

“源码探索”显示固定提交与文件出处。Squirrel 使用 1.1.2 标签；librime / plum 是研究快照，不能直接假设等同于本机版本。社区能力需要确认方案、插件、词典及版本依赖。


## 获取和更新方案

打开“方案与词库 → 获取和更新方案”，选择雾凇或白霜，点击下载。下载需要 Git 和网络，完成后显示文件预览，尚未写入 Rime 用户目录。

首次完整安装会把主方案加入菜单首位，保存后可在“输入方案”调整启停与顺序。上游的个人短语样例和 `.custom.yaml` 不会导入，但其他同名源文件可能被替换，务必核对预览。保存后请求重新部署。

安装记录绑定实际下载的提交和每个文件的 SHA-256。“检查整套更新”包含方案、词库、Lua、OpenCC 与随包模型；“只更新词库”只更新 `.dict.yaml`，需要已由知键完整安装该方案。更新不会强制重新启用或调整菜单顺序。

已被本地修改的上游文件会保留并列为冲突；需要核对与新文件的兼容性。上游删除的文件暂时保留，不自动移除。下载任务只在当前服务进程中保留，预览有效期为十分钟。重启或预览过期后重新下载和预览。

## 查询词库与添加个人词条

“我的词库”显示已发现的文本词库、来源目录、引用关系及所选方案的主词库。存在编译配置时优先显示编译后的引用；保存后需部署才能刷新这些关系。

点击词库，按文字或编码搜索，每页最多显示 100 条。原词库只读；点击“编辑个人扩展词库”，添加文字、完整编码及权重，预览后保存。个人词条另存为独立词库，扩展入口展开原词库依赖，同时保留原来的用户学习词典名称。

双拼方案的词库通常仍使用全拼编码，不能直接填写按键缩写。带声调或辅助码的编码需遵循原词库。特殊列结构、缺失依赖和引用循环拒绝自动扩展。

## 编辑快捷短语

“快捷短语”选择方案后读取其已识别的文本短语表。不存在可识别的短语翻译器时，首次保存会创建独立短语文件并接入翻译器；不安全的高级补丁会拒绝合并。引用多个短语表的方案暂不支持合并编辑。

编辑输出文本、输入缩写和权重；可新增、移除、导出和导入 UTF-8 的 TXT／TSV 文本。导入格式为“文字 Tab 编码 Tab 权重”，权重可省略。最多 2000 条、100 KB，不支持多行文本、额外列或任意格式词库。空白编辑行忽略；已有完整注释行保留，但编辑表会统一数据行格式。

大型词库和二进制模型不生成完整逐行差异，预览显示文件大小及 SHA-256；保存和恢复仍核对完整内容。从“调整我的输入 → 修改记录”可恢复这批文件。
